# 选题 → 框架 对照表

看到某类素材,查这张表知道该用他哪把框架去拆。所有框架共一根脊柱:**复杂系统自发秩序 + 反身性正反馈**——系统自己会算,人越想操纵越付代价。

## 总脊柱:自发秩序 + 反身性正反馈

适用一切。核心判断模板:
- 这是分布式计算(健康),还是自我循环(末期泡沫)?
- 系统在自我强化(正反馈)还是自我修复(负反馈)?
- 人是在顺应趋势,还是在操纵系统?**操纵必被系统反噬**(涨价去库存、推股市、夺定价权、集中力量办大事——都是低估复杂系统)。

## 七把具体框架

| 框架 | 适用题材 | 核心命题/打法 |
|---|---|---|
| **信用=价格** | 通缩/通胀、房产、债务、汇率 | "价格是信用的一部分"。通缩=信用收缩,不是价格下跌。价格既是结果也是过程。操纵局部价格撬不动整张信用网络 |
| **自发秩序** | 趋势、市场、政府能不能控制 | 趋势/市场是所有人合力的自组织,不是某人某政府能左右。政府趋势上涨时"狐假虎威",老虎不发威狐狸喝令不了百兽 |
| **算力/分布式计算** | 趋势逆转、泡沫末端 | 趋势=汇聚所有人的最高算力。末端算力压缩、降维、退化成价格自我循环,不再计算未来。最终逆转触发是流动性的物理极限,不是基本面 |
| **风险回报率格栅** | 任何资产(股/金/币/房) | 一切落到上行空间vs下行空间。增长才是真正的安全边际(不是便宜)。捡烟蒂上行封死下行敞开,风险回报率差。复利vs单利。一国股市=对该国未来增长的集体投票 |
| **凹凸/二阶** | 加速还是减速、市场状态 | 不看涨跌看二阶:凸性(加速)还是凹性(减速)。收益是上行敞开还是下行敞开 |
| **量化(LPPL等)** | 判断具体标的是否泡沫 | 对数周期幂律、超指数增长、日内波动率Sigma、发散不收敛、R²。**需真实数据。冷静克制不升维** |
| **账本四问** | 补贴/出口信贷/基建/地方债/产业政策/国企银行行为 | 谁需要这笔交易发生?谁有权推动?谁拿眼前收益?谁担最终损失?第四问必须答到底。详见下节 |

## 第七把:账本四问(制度与激励)

**适用**:补贴、出口信贷、基建投资、地方债、产业政策、国企/银行行为、任何"看起来不该发生却持续发生"的交易。

脊柱说"操纵必被系统反噬"。这把框架补的是另外半句:**操纵为什么能持续、反噬最后落在谁头上。** 不用它,这类题材只能写到"系统会反噬"就停,写不出账是怎么分的。

这类题材出稿前必答四问,缺一不可:

1. **谁需要这笔交易发生?** 从交易居然成立,反推对手方的约束。有钱有融资渠道的人不需要你的贷款;需要你贷款才买得起的,一定是别处借不到的。**交易本身就是对手方处境的证据。**
2. **谁有权推动?** 决策权和出资权常常不在一个主体手里。谁签字、谁掏钱,是不是同一个人。
3. **谁拿眼前收益?** 收益通常当期确认、归属明确——订单、产值、就业、税收、业绩。
4. **谁担最终损失?** 损失通常长期显现、归属模糊。**这一问必须答到底,不许停在中间主体。**

第四问是这把框架的全部价值,也是最容易烂尾的地方。停在"银行承担"不算答完——银行不是终点,损失还要往下传:财政注资、存款利率压制、货币稀释。**追到那个既不能拒绝、又没人征求过意见的主体为止。**

配套判断:**损失以什么货币计价,决定它能不能被稀释掉。** 本币计价的坏账可以靠时间和货币化内部消化,外币计价的不行。所以"用哪种货币放贷/举债"往往不是技术选择,是在挑由谁买单。

同理还有流动性:通用的、随时可变现的债权(如储备货币资产),和专用的、只能靠展期维持账面价值的债权,风险完全不是一回事。账面上都是"资产",实质差一个量级。

### 与脊柱的接法

四问答完再接回脊柱收尾:收益当期、损失长期,本身就是一种正反馈——每个参与者都在对自己的KPI做最优决策,成绩单各自漂亮,系统的账却记在另一本上,合起来是集体的次优。这就是"操纵复杂系统必付代价"的具体形态,只不过代价换了个人付。

### 政治边界(必须守)

四问只走到**经济主体的激励与账本**:企业、银行、地方财政、储户、纳税人——谁的KPI、谁的资产负债表、谁的现金流。

**不许走到**:某个政府决策对不对、体制优劣、哪国做法更好、某人某部门该负责。一旦第二问("谁有权推动")的答案要写成对具体权力机构的评价,立刻退回激励层面——只描述"决策权与出资权分离"这个结构,不点名、不评判。

判断线:写"这笔账最后由存款人用长期低利率支付"是安全的(机制);写"某某政策失误导致…"就越界了(评判)。

## 形而上母题(信仰篇用)

- **秩序/真理**:穿透表象到底层规律=寻找神留下的痕迹;研究复杂系统是一种朝圣。
- **心魔/骄傲**:人的自我(Ego)无法自我驯服;投机取巧、想操纵世界=对世界算力的无知,必付更大代价。
- **真善美**:真是内核;虚假的善是欺骗工具,虚假的美是吃人的画皮。

## 标志性比喻(挑着用,别全堆)

- 信用潮汐/潮水(价格不是水位,是潮水本身)
- 温度计(否定用:价格不是外部温度计,是网络内部节点)
- 开车只有油门没有刹车(只会加入不会退出)
- 左脚踩右脚(自循环的杠杆推动)
- 按钮 vs 网络(想用一个按钮撬动整个复杂网络)
- 牛鞭效应(终端需求变化被供应链层层放大)
- 饮鸩止渴、狐假虎威、雪上加霜(成语压场)
