# 论证架构(文章和视频口播稿共用)

style-rules.md 管句子怎么写,这里管整篇怎么排。2026-11-02 从一期财经视频(一个狠人《共识说崩就崩》)拆出来,只取结构,不取内容。

## 一、动笔前先列问题链

正文不按"背景、分析、结论"排,按**一串问题**排。动笔前先写下 3-5 个问题,每个问题的答案引出下一个问题:

```
Q1 为什么 X 会突然崩?        → 答:撑着它的独立证据很少
Q2 为什么人多证据却少?      → 答:大家用的是同一份来源
Q3 那为什么是同一秒崩?      → 答:所有人同时碰到临界点
Q4 崩之前有没有信号?        → 答:看分歧度
```

- 一段只回答一个问题。答完这段,用一句话把下一个问题抛出来:"这解释了〔A〕,但没解释〔B〕。" 这句话就是段落之间的拉力,读者是被问题拽着往下读的。
- 问题按依赖排序:后一个问题必须在前一个答案的基础上才问得出来。能互换顺序的两个问题,说明没串上,重排。
- 问题链和核心命题的关系:核心命题是最后的总答案,每个问题都是它的一块拼图。

## 二、开头:反常数字 → 结论前置

开头可以用 style-rules.md 的三种开法,也可以用第四种:

**反常数字开场**:第一句给一个和直觉反着、核实过的具体数字,第二句立刻落到核心命题。

> 韩国股市今年熔断了 10 次,而它有熔断制度以来一共才 16 次。〔核心命题〕。

紧接着用一句**路标句**把结论前置:"先把结论放在这里,后面每一段都在解释它。" 读者知道要往哪听,中途不容易走。路标句全篇只用一次。

开头两段仍受 style-rules 的数字密度限制:开场数字最多 2 个。

## 三、抽象概念走阶梯

一个抽象概念要从零门槛的例子起步,一层只抬一级:

> 抛硬币 → 一个消息能把可能性砍掉一半 → 证据也能这样计量 → 多份证据如果不独立就不能相加 → 九亿人等于一个半人

- 每层都要有一个具体画面,遵守 style-rules「能换画面就别解释」。前面立起来的画面后面接着用,不换比喻。
- 跳级是最常见的劝退点:读者卡在某一级,后面全白写。写完回读,每一级问一句"上一级没读懂的人能不能读懂这一级"。

## 四、借模型、引研究要准

跨学科模型(物理、信息论、生态学、营销学)和学术研究可以用,它们给文章提供硬度,但有三条硬规则:

1. **写出作者和年份**,并用 WebSearch 核对原文结论确实是这个意思。核不到就不引。
2. **交代研究的设定**:是模拟还是真实数据、研究对象是什么(比如"强化学习代理在模拟赎回博弈里")。设定和文章论点不是同一类对象时,必须明说,不许拿 A 类对象的结果去证明 B 类对象。
3. **同一篇研究里有反方结果,要提一句。** 只引对自己有利的那一半,懂行的读者一核对,整篇的信任就没了。

## 五、推导出来的数字要标明是推导

用公式算出来的数(比如"按相关系数 0.7 算,等于 1.4 个独立的人"),必须同句写明它依赖的假设,而且假设本身要么有出处,要么明说"这是我取的值"。

**不许把假设参数算出的结果当成测量结果来写。** 这类数字最唬人,也最经不起追问。

## 六、自己测的数字(有条件时必放)

题材是 BTC 或加密市场、并且在本机运行(能碰到 `E:\回测引擎` 的 OKX 缓存数据)时,优先放一个**我们自己测出来的数字**,写明样本区间和口径:

> 用 2020-2026 年 OKX 永续合约的数据算,2024 年以后 BTC 每年最大的单小时跌幅都没超过 5%。

所有统计必须走回测引擎(不写一次性脚本)。在云端 routine 里碰不到本机数据,这一节跳过,不要编。

## 七、落地 → 缺陷 → 收尾

正文讲完机制后,按这个顺序收:

1. **落地**:给读者一个可以自己做的观察或判断方法("盯 X 和 Y 的分歧"),不是买卖建议。
2. **缺陷段**:一到三句,说这个框架或方法**在什么情况下会失效**。要具体:"用的人多了,这个价差就会被提前定价吃掉。" 默认模式也要有这一段,它是框架的边界,不是对方向打折;诚实模式下,方向的证伪条件按 honest-mode.md 另写。
3. **收尾**:末句金句照 style-rules,然后免责声明。

## 八、系列化

同一母题(同一 category 下、同一条核心框架)写到第二篇起:

- 开头一句话回顾上一篇的核心命题,并链到那篇文章。
- 一篇只推进一步,不把上一篇重讲一遍。
- 结尾可以留一句下一篇要回答的问题。

## 不学的两件事

拆的那期视频有两处做法不学,写进这里防止滑回去:

- 用假设参数算出精确数字,再当成事实反复引用(见第五节)。
- 引研究只讲对自己有利的那一半(见第四节第 3 条)。
